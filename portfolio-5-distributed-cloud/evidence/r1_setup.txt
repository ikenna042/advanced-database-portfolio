
== Nodes ==

node1 was created with initdb. node2 and node3 were cloned from it with pg_basebackup
and stream its write-ahead log (WAL). The schema and data were then loaded on node1 only.
synchronous_standby_names on node1 is 'FIRST 1 (node2)': a commit waits until node2 has
the WAL on disk. node3 is asynchronous.

[node1] SELECT current_setting('cluster_name') AS node, version() ~ 'PostgreSQL 16' AS pg16,
                 CASE WHEN pg_is_in_recovery() THEN 'standby' ELSE 'primary' END AS role
     node  | pg16 |  role   
    -------+------+---------
     node1 | t    | primary

== Replication as node1 sees it ==

[node1] SELECT application_name AS standby, state, sync_state,
       pg_wal_lsn_diff(pg_current_wal_lsn(), replay_lsn) AS bytes_not_yet_applied
  FROM pg_stat_replication ORDER BY 1
     standby |   state   | sync_state | bytes_not_yet_applied 
    ---------+-----------+------------+-----------------------
     node2   | streaming | sync       |                     0
